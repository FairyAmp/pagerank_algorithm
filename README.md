# PageRank Grocery List Sorter

This project applies the **PageRank algorithm** (traditionally used by Google for web search) to an unusual and practical domain: **sorting and prioritizing a grocery shopping list**. Developed in 2023 as part of coursework, it models grocery items.

The repository features dual implementations in **Python** and **MATLAB**, alongside a formal **LaTeX report** which details the graph construction, transition probability matrix, and convergence analysis.
